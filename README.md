# Converter CSV to Parquet
Convertidor básico de CSV a formato Parquet mediante una interfaz gráfica sencilla 

## Librerías usadas
- duckdb: Conversión de archivo
- tkinter: Interfaz gráfica de usuario
- threading: Evitar que la ventana principal se congele
- pathlib: Manejo de rutas
- time: Medición de tiempo de ejecución
- random: Mensajes aleatorios para mostrar que la aplicación sigue trabajando y no se ha congelado
